# Moon Healing

Landing page for Moon Healing, reiki and massage in Hải Châu, Da Nang.

Static site with no build step: `index.html`, `moon.webp`, `avatar.webp`, `favicon.svg` and `vercel.json`.

Live: https://moon-healing-zeta.vercel.app

## Edit
- Prices, hours and address live in `index.html` (search for "VND", "OPEN=" or "Đ. 3 Tháng 2"). Hours: Tue–Fri, 10 AM–12 PM, by appointment only.
- Booking buttons point to https://www.instagram.com/moonhealing_reiki_massage/

## Run locally
Open `index.html` in a browser, or run `npx serve .`

## Deploy
Vercel: import the repo as a project with framework preset "Other" and no build command.
